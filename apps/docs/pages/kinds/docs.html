Paste the prompt into any LLM. It asks about your documentation in short rounds, shows you the plan and writes nothing until you say "go".

Open the prompt

Or build it yourself from the recipes below. They use the classes of core, the catalog and docs only; Install LUZ lists the files to load. The page you are reading is made of them.

Shell

The whole page: the header, the sidebar, the rail, the content and the footer, in the order a keyboard reaches them. The skip link goes to the content, past the sidebar and the rail. The shell is three columns from 80rem, two from 60rem and one below, with the rail above the content when there is no third column.

It has no example inside this page, as it is the whole page: this one is built on it. Resize the window to see its columns.

Rail

"On this page" and the actions on the page, beside the content from 80rem and above it below: the rail, a direct child of the shell, between the sidebar and the content. The rail of this page is a live one. A link of the list also carries the catalog's .luz-sidebar__link, so the catalog's script marks the section in view as you scroll.

Do and don't

A pair that shows the right way and the wrong one, the Do first: the do and don't. Each is a figure whose caption says why. The word, the mark before it and the frame say which is which, so the colour is never the only cue.

<div class="luz-docs-dodont">
  <figure class="luz-docs-dodont__item luz-docs-dodont__item--do">
    <figcaption><strong class="luz-docs-dodont__verdict">Do</strong> Title a page for what it lets the reader do.</figcaption>
    <div class="luz-docs-dodont__stage" inert aria-hidden="true">
      <h3>Install the command line tool</h3>
    </div>
  </figure>
