What the home FAQ left out.

HTML and classes

Do HTML elements have a style without any class?

Yes: with luz.css, native HTML comes out styled.

Which HTML elements have no style?

Those that only structure the page, such as div and nav.

What are the LUZ classes for?

For what HTML cannot say: sizes, roles and components with their own markup.

Does a class change how an element looks?

Very little: it adds what needs markup or a role.

Is LUZ classless?

Yes, and it also has components and a catalog.

Existing projects

Is LUZ only for new projects?

No: an existing project is migrated page by page with luz.conditional.css.

Is it worth migrating from another system?

For a content site, yes; for a single-page app on a UI library, no.

How do I migrate, and how does the AI help?

In phases, one page at a time: the AI does the mechanical work, you decide.
