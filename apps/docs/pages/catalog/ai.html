Example

Experimental. It works only in Chrome 148 or later on a computer, it can be wrong, and its API may change in a minor release. Answers come from this site’s own pages, written by a model that Chrome keeps on your device: your questions are not sent anywhere. Elsewhere the example shows its note and a link instead.

This chat needs Chrome 148 or later on a computer. Without it, read the documentation or use the search at the top of the page.

Without JavaScript, or in a browser with no model, you see the note and the link above.

Known issues

  • It works only in Chrome 148 or later on a computer; Firefox and Safari do not have the API.
  • The model is small: it can invent or miss things. Check what matters on the page.
  • A page cannot delete the model Chrome downloaded; Chrome does it, at chrome://on-device-internals.
  • It has not been tested with a screen reader.
