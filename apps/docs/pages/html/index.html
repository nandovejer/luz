How to read a card

  • Live example. The real element, styled by LUZ right now. Change the color mode in the page footer to check it in all three.
  • Markup. The exact code of the example. The copy button copies what you see.
  • LUZ note. Whether the element is styled with no class, left to the browser, or has no style because it only groups content. When a class adds something, the note says what.

Rules that style bare elements have zero specificity: any .luz-* class, or a rule of your own, wins.

The HTML says the variant

A class is not needed to tell one look from another when the HTML already says it:

  • A button with no type, or with type="submit", is the primary action. type="button" and type="reset" are the secondary one.
  • aria-invalid="true" marks a field with an error.
  • disabled marks a control that cannot be used.
  • aria-current="page" marks the link of the page you are on.

A class adds what HTML cannot say: a link that looks like a button, the danger and ghost roles, the sizes, and the parts that need markup of their own. The card of each element says what its class adds. An element with a luz-* class takes the look of its component.

Changing the default styles

Every rule that styles a bare element has zero specificity, so yours wins without a fight.

  • Change the tokens. This is the way to change the look of the whole site: colors, type, space and radius. Copy themes/_template.css and change the values. Make it yours shows how.
  • Write your own CSS. CSS with no layer beats every layer of LUZ. You need no !important and no longer selector. What you leave alone stays: if you change only the color of an h1, it keeps the size LUZ gives it.
  • Use LUZ in one region of a page that already has a design. Load luz.conditional.css instead of luz.css, and put data-luz on the element that holds the region. The reset and the bare elements apply only inside it. Which level do I need? says when to choose it.
CSS 
/* Your CSS has no layer, so it beats every layer of LUZ. */
h1 {
  font-weight: 600;
}

button {
  border-radius: 0;
}

The tokens, your CSS and the region work together: the tokens change what LUZ draws, your CSS has the last word, and the region limits where LUZ draws at all.
