Copy the markup

A separate stylesheet: link components/bar-list.css after luz.css.

HTML 
<figure class="luz-bar-list">
  <ul class="luz-bar-list__rows">
    <li class="luz-bar-list__row">
      <span class="luz-bar-list__name">Sevilla to Madrid</span>
      <span class="luz-bar-list__figure">1,204</span>
      <meter class="luz-bar-list__meter" max="1500" value="1204" aria-hidden="true">1,204 of 1,500</meter>
    </li>
  </ul>
  <figcaption>Parcels per route, this week</figcaption>
</figure>

How it works

A list in a figure: each row is a name, a figure and a native meter, drawn in --luz-chart-1 with the track in --luz-chart-track. Give every row the same max. A long name is cut to one line. Unlike .luz-meter, the meter has no minimum width, so it never widens a narrow card.

Without JavaScript

It needs none. Without the stylesheet it reads as a list of names and figures.

Keyboard and ARIA

Nothing takes focus. The name and the figure are text: hide the bar with aria-hidden="true". A meter left visible needs a name.

Contrast and focus are in the Design tab.

Design

When to use

Use it to compare a few values on one scale: sizes, counts, shares.

When not to use

Do not use it for one value (use a meter) or for a trend over time. Keep a table when exact values matter most.

Do and don't

Writing the content

Name the unit and the period in the caption (“Parcels per route, this week”), keep each name short, and write the figure with its unit.
