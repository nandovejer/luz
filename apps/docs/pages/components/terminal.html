Example

An install command, in two tabs: npm and the CDN.

npm CDN 
npm install @luz-ds/core
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/core@0.1.0/dist/luz.min.css">

Open the CDN tab, then press Copy: the button copies the command of the open tab. Only the npm command shows a $ prompt.

How it works

A tab row, a copy button and a code block in one frame, styled by components/terminal.css. It has no script of its own: it is tabs, a copy button and a code block.

  • initTabs() upgrades the row and shows one pane at a time. luz.js runs it.
  • initCopyButtons() copies the data-copy text of the button. luz.js runs it.
  • The copy button of the open pane sits at the end of the title bar. The code block shows no language label.
  • The command is a .luz-terminal__code, not a .luz-code-block, so highlight.js leaves it alone: it adds no second copy button and no syntax colours.
  • The prompt is drawn by CSS, so it is not part of the text the button copies.

Without JavaScript

The title bar is a row of links, and every pane is shown, stacked, in order. Each link jumps to its pane.

The copy buttons are hidden, because they would do nothing. The command stays on the page, so the reader selects and copies it.

Keyboard and ARIA

Tab moves into the title bar, to the selected tab; Tab again goes to the copy button, then to the command.

  • Left and Right (or Up and Down) move to the next tab and select it; Home and End go to the first and the last. In right-to-left text, Left and Right follow the reading direction.
  • Enter or Space presses the copy button. Focus stays on it.
  • Name the tab row with aria-label, and each code block with aria-label and role="region": the block scrolls, so it takes focus.
  • The visible label of the button is “Copy”; its aria-label starts with it and says what is copied. The result is announced in the polite live region shared by every copy button.

Design

When to use

Use a terminal for a command the reader will paste into a shell, or a line to add to a page, that comes in more than one form: npm or the CDN, one package manager or another.

When not to use

Do not use a terminal for code that is not a command, or for a single form with nothing to switch.

  • For code to read, such as markup or styles, use a code block.
  • For one value to copy, use a copy button next to it.
  • For a long session with its output, use a code block the reader can select.

Do and don't

Writing the content

Name each tab after the way, in one word: “npm”, “CDN”. The source is written as is; the stylesheet shows it in capitals.

  • Write the command without the prompt sign: for data-lang="bash" the stylesheet adds it.
  • Copy exactly what is shown, with no extra spaces and no placeholder the reader must change first.
  • Start the accessible name of each copy button with “Copy” and say what it copies: “Copy the npm command”.
