Lo que las preguntas frecuentes de la home dejaron fuera.

HTML y clases

¿Tienen estilo los elementos HTML sin ninguna clase?

Sí: con luz.css, el HTML nativo sale con estilo.

¿Qué elementos HTML no tienen estilo?

Los que solo estructuran la página, como div y nav.

¿Para qué sirven entonces las clases de LUZ?

Para lo que el HTML no puede decir: tamaños, roles y componentes con marcado propio.

¿Una clase cambia el aspecto de un elemento?

Muy poco: añade lo que necesita marcado o un rol.

¿LUZ es classless?

Sí, y además tiene componentes y un catálogo.

Proyectos que ya existen

¿LUZ es solo para proyectos nuevos?

No: un proyecto que ya existe se migra página a página con luz.conditional.css.

¿Merece la pena migrar desde otro sistema?

Para un sitio de contenido, sí; para una app de una sola página sobre una biblioteca de UI, no.

¿Cómo migro, y cómo ayuda la IA?

Por fases, una página cada vez: la IA hace el trabajo mecánico y tú decides.
