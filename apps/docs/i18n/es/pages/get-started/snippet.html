Cada fragmento carga primero los tokens, luego core y, por último, el paquete para el tipo de sitio que uses, en el orden que esperan las capas de cascada. El paquete site es opcional para una landing page, un blog y una aplicación, por eso sus líneas están marcadas y puedes eliminarlas sin riesgo.

Para ver la explicación paso a paso, lee Instalar LUZ; si usas una herramienta de compilación, consulta Con un empaquetador o framework.
