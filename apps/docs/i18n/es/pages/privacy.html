Quién gestiona este sitio

Este sitio lo gestiona Fernando Muñoz (GitHub: nandovejer), que también escribe LUZ. No tiene anuncios, ni analítica, ni cuentas, y no te pide datos personales. Este sitio no establece cookies por sí mismo.

Dónde está alojado

El sitio está alojado en GitHub Pages. GitHub registra en sus servidores la dirección IP de quienes lo visitan, por seguridad, y nosotros no podemos ver esos registros. Cómo trata GitHub Pages los datos de los visitantes se explica en GitHub.

Qué se guarda en tu navegador

El sitio guarda unos pocos datos pequeños en el almacenamiento local de tu navegador. Cada uno se escribe solo después de que hagas algo que lo pide, como elegir un modo de color. Ninguno se envía a un servidor y cada uno se usa solo para lo que dice su fila.

Vídeos de fuera

Una página de este sitio, Incrustado, puede reproducir un vídeo de YouTube. No se pide nada a YouTube hasta que pulsas reproducir y aceptas.

Si reproduces el vídeo, YouTube (Google) recibe tu dirección IP y datos de tu navegador, y puede guardar información en tu dispositivo. Nosotros no recibimos nada de eso. A partir de ese momento se aplica la política de privacidad de Google.

Sin JavaScript, el vídeo es un enlace a YouTube. Si lo sigues, sales de este sitio.

Ajustes de cookies

La única elección que te pregunta este sitio es la de los vídeos de YouTube. Si no has respondido, la pregunta está en la parte inferior de esta ventana. Usa el botón para verla de nuevo y cambiar tu respuesta.

Sin JavaScript, la pregunta y el botón permanecen ocultos, porque el vídeo es solo un enlace y el sitio no guarda nada.
