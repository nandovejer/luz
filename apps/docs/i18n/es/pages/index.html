Cómo funcionan estas páginas

  • Cada página de componente y patrón muestra primero un ejemplo interactivo y sus problemas conocidos, y después dos pestañas: Código para desarrolladores y Diseño para diseñadores.
  • Las páginas se abren en Código. Si eliges Diseño, la siguiente también se abrirá en Diseño: este navegador recuerda tu última elección, igual que recuerda el modo de color. No se envía nada.
  • Sin JavaScript, las dos pestañas se muestran una detrás de otra.
