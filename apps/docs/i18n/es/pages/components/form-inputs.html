Rango

Un deslizador para un valor en una escala, donde la posición del control importa más que el número exacto.

Código Diseño

Código

Copiar el marcado

Un deslizador con min, max y step, y un <output> que muestra su valor. El deslizador no muestra ningún número propio, así que unas pocas líneas de tu propio script actualizan el resultado:

HTML 
<div class="luz-field">
  <label class="luz-field__label" for="volume">Volume <output class="luz-output" id="volume-out" for="volume">50</output></label>
  <input class="luz-input" id="volume" type="range" min="0" max="100" value="50">
</div>
JS 
const range = document.getElementById("volume");
const output = document.getElementById("volume-out");
range.addEventListener("input", () => {
  output.value = range.value;
});

Variantes y opciones

  • min, max, step: la escala y el tamaño de un paso.
  • disabled: atenuado, la tecla Tab lo salta y no se envía. Un rango no tiene estado de solo lectura.
  • Sin un <output>, el lector no puede ver el número: añade siempre uno.

Cómo funciona

Un <input type="range"> nativo. .luz-input[type="range"] asigna a accent-color el valor --luz-brand-primary, así que el control y la pista rellena siguen la marca. LUZ no tiene ningún script para el resultado: el tuyo escucha el evento input.

Sin JavaScript

El deslizador funciona y envía su valor. Sin tu script, el resultado sigue mostrando el valor inicial.

Teclado y ARIA

  • Tab lleva el foco al deslizador. Izquierda y abajo restan un paso, derecha y arriba suman uno. Inicio y Fin van a los extremos.
  • La etiqueta es el nombre; une el resultado al deslizador con for.

El contraste y el foco están en la pestaña Diseño.

Diseño

Cuándo usarlo

Usa un rango cuando el lector fija un valor a ojo y basta una respuesta aproximada.

  • El volumen, el brillo o un presupuesto aproximado.
  • Muestra el valor junto al deslizador y fija min, max y step según lo que necesites.

Cuándo no usarlo

No uses un rango cuando importa el número exacto o la escala es larga.

  • Una cantidad exacta: un campo de número.
  • Unos pocos niveles con nombre: botones de radio con los nombres.

Qué hacer y qué no

Cómo escribir el contenido

  • Ponle una etiqueta según lo que fija: «Volumen», «Brillo».
  • El resultado contiene solo el número; pon la unidad en la etiqueta: «Volumen, %».
  • Di en la pista los extremos de la escala si no son obvios.
