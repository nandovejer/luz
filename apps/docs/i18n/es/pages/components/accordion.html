Ejemplo

Un grupo de preguntas con sus respuestas: al abrir una, se cierra la que estaba abierta.

What is a design token?

A named value, such as a color or a space, that components read instead of a literal.

Why only one open at a time?

The same name on each details connects them: opening one closes the other.

Does it need JavaScript?

No. The browser opens, closes and groups them.

Problemas conocidos

Hay dos cosas que debes saber antes de confiar en un grupo con nombre.

Grupo exclusivo. El atributo name funciona en Chrome y Edge 120, Safari 17.2 y Firefox 130, todos desde septiembre de 2024 o anteriores, por lo que aún no tiene disponibilidad amplia en Baseline. En un navegador más antiguo, cada panel se abre por separado: no se pierde nada.

Lectores de pantalla. LUZ no ha probado cómo anuncian NVDA, JAWS, VoiceOver, TalkBack y Orca un grupo exclusivo, ni ha comprobado datos de compatibilidad. La agrupación de un conjunto exclusivo no se comunica a la tecnología de asistencia: su correspondencia de accesibilidad en HTML sigue siendo una cuestión abierta (consulta la explicación de Open UI).

Variantes y opciones

Un único <details> no necesita clase: la capa de elementos le da estilo. La clase solo sirve para unir varios en una pila.

Clase o atributoQué hace
.luz-accordion
Une los elementos <details> que contiene en un solo bloque: un borde entre ellos y esquinas redondeadas solo en el bloque
name="…"
Agrupa los elementos details con el mismo nombre: solo puede haber uno abierto a la vez. No tienen que estar juntos
open
Hace que un panel empiece abierto. En un grupo con nombre, solo permanece abierto el primer elemento con open en el código fuente

Cómo funciona

Elementos nativos <details> y <summary>, con estilos de elements/interactive.css y sin clases. components/accordion.css solo añade el bloque unido.

No necesita JavaScript.

  • summary es la etiqueta del panel; el resto de details es su contenido.
  • El contenido cerrado no se muestra ni forma parte del orden de lectura hasta que se abre el panel.

Sin JavaScript

No cambia nada: el navegador se encarga de abrir, cerrar y agrupar. El acordeón funciona por completo sin scripts.

Teclado y ARIA

Con Tab se llega a cada summary en orden. Enter o Espacio lo abre o lo cierra.

No hay atajos con las teclas de flecha para moverse entre paneles.

  • No añadas ningún role: <details> ya tiene su propia semántica y no admite roles ARIA.
  • No pongas enlaces ni botones dentro de summary: ese elemento ya es el control.

El contraste y el foco están en la pestaña Diseño.

Diseño

Cuándo usarlo

Usa un acordeón para agrupar bajo títulos breves contenido que la mayoría de lectores puede omitir.

  • Preguntas frecuentes y listas de referencia largas.
  • Detalles opcionales bajo una respuesta breve.

Cuándo no usarlo

No ocultes información que necesitan todos los lectores ni lo uses para desplazarte por el sitio.

  • Para las secciones principales de un sitio, usa una barra lateral. Para contenido entre el que se puede alternar, usa pestañas.
  • No pongas un error, un aviso ni un paso obligatorio dentro de un panel cerrado.
  • Si solo hay una o dos respuestas breves, muéstralas como texto normal.

Qué hacer y qué no

Cómo escribir el contenido

  • Escribe en summary la pregunta o el tema, con mayúscula inicial y en pocas palabras.
  • Pon primero la respuesta en el panel. Sé breve y enlaza a otra página para ampliar la información.
  • Ordena los paneles según las preguntas de los lectores, empezando por la más frecuente.
