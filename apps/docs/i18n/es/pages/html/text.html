    Patrones de listas de descripciones

    Tres formas de usar <dl> con los estilos anteriores. Puedes agrupar cada <dt> con su <dd> en un <div>: es HTML válido y LUZ mantiene el mismo espacio entre grupos.

    Metadatos

    Datos sobre algo, como un archivo o un pedido. Cada par tiene un nombre y un valor, y va en su propio div para que un script o una regla de estilo pueda seleccionarlo.

    File
    annual-report.pdf
    Size
    2.4 MB
    Last changed
    9 October 2026
    HTML 
    <dl>
  <div>
    <dt>File</dt>
    <dd>annual-report.pdf</dd>
  </div>
  <div>
    <dt>Size</dt>
    <dd>2.4 MB</dd>
  </div>
  <div>
    <dt>Last changed</dt>
    <dd><time datetime="2026-10-09">9 October 2026</time></dd>
  </div>
</dl>

    Usa <time> con datetime para las fechas. Los nombres son sustantivos breves y los valores, texto sin formato.

    Pares de nombre y valor

    Un resumen de ajustes o detalles. Un nombre puede tener varios valores: repite dd, uno por cada valor.

    Plan
    Team
    Members
    Ana Ruiz
    Luis Pérez
    Billing email
    billing@example.com
    HTML 
    <dl>
  <div>
    <dt>Plan</dt>
    <dd>Team</dd>
  </div>
  <div>
    <dt>Members</dt>
    <dd>Ana Ruiz</dd>
    <dd>Luis Pérez</dd>
  </div>
  <div>
    <dt>Billing email</dt>
    <dd><a href="mailto:billing@example.com">billing@example.com</a></dd>
  </div>
</dl>

    Si un nombre tiene varios valores, todos forman un mismo grupo: el lector de pantalla anuncia cada valor por turno.

    Glosario

    Términos y sus significados. Cada término es un dt con un dfn dentro y tiene un id para que otras páginas puedan enlazar a su entrada.

    Design token
    A named value, such as a color or a space, that components read.
    Color mode
    One set of color values for the whole page.
    Light, dark and high contrast are the three LUZ ships.
    HTML 
    <dl>
  <dt id="term-token"><dfn>Design token</dfn></dt>
  <dd>A named value, such as a color or a space, that components read.</dd>
  <dt id="term-mode"><dfn>Color mode</dfn></dt>
  <dd>One set of color values for the whole page.</dd>
  <dd>Light, dark and high contrast are the three LUZ ships.</dd>
</dl>

    Enlaza a un término con #term-token. Un término puede tener más de un significado: repite dd.

    Antes de usarlo

    • Mantén el valor predeterminado de display de <dl> y sus grupos. Definir flex o grid en elementos de lista ha hecho que algunas combinaciones de navegador y lector de pantalla pierdan la semántica de lista; consulta Propiedades display de CSS frente a la semántica de HTML. Distribuye los pares en un contenedor que controles y prueba el resultado.
    • HTML solo permite un <div> dentro de <dl> cuando envuelve un nombre y sus valores. Una fuente que probó un div como contenedor simple detectó problemas con lectores de pantalla en algunos navegadores (Uso de div en dl; no ofrece resultados). LUZ no ha probado el marcado agrupado con NVDA, JAWS, VoiceOver, TalkBack ni Orca.
    • Para una tabla con muchos valores por fila, usa una tabla, no una lista de descripciones.
