Cómo contactar con quienes están detrás del artículo más cercano o de toda la página: una dirección de correo, un teléfono o un enlace a un perfil. No se usa para direcciones postales mencionadas en el texto. Los navegadores lo muestran en cursiva; LUZ lo pone en redonda y con el color secundario.

<main>

Envuelve el contenido propio de esta página, sin el encabezado, la navegación ni el pie que se repiten en todas. Solo puede haber un main visible, así que esta tarjeta muestra solo el marcado: la página que estás leyendo ya está dentro de uno.

<nav>

MDN referencia del elemento nav

Envuelve los enlaces que sirven para moverse por el sitio o la página. Si hay más de uno, ponle un nombre a cada uno para que las personas que usan lectores de pantalla los distingan.

Home · Docs · Site
HTML 
<nav aria-label="Example navigation">
  <a href="#">Home</a> ·
  <a href="#">Docs</a> ·
  <a href="#">Site</a>
</nav>

LUZ no añade estilos: es un punto de referencia, no una caja visual. Un nav con una lista es una lista normal; para una fila de enlaces usa .o-row, y para las migas de pan y la barra lateral, LUZ tiene componentes con sus propias clases.

<search>

MDN referencia del elemento search

Envuelve un formulario de búsqueda o filtro; así, los lectores de pantalla lo anuncian como una región de búsqueda. No necesita el atributo role.
HTML 
<search>
  <form action="#">
    <label for="d-search">Search the docs</label>
    <input class="luz-input" id="d-search" type="search" name="q">
    <button class="luz-btn luz-btn--primary" type="submit">Search</button>
  </form>
</search>

LUZ no añade estilos: es una región, no una caja visual. El formulario que contiene define su aspecto.

Conviene usarlo

Úsalo alrededor del formulario y los controles de una búsqueda o filtro para que los lectores de pantalla lo anuncien como una región de búsqueda sin atributo role. No es para los resultados: estos van en el contenido principal. Las sugerencias de búsqueda rápida que formen parte de la búsqueda sí van dentro. Disponible de forma general desde octubre de 2023.

Varias búsquedas: El ejemplo de MDN distingue dos búsquedas de una misma página mediante title. Pon un nombre distinto a cada una.

Fuente: MDN, consultada el 11 de octubre de 2026.
