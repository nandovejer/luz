Cómo leer una ficha

  • Ejemplo en vivo. El elemento real, con los estilos de LUZ. Cambia el modo de color en el pie de página para comprobarlo en los tres modos.
  • Marcado. El código exacto del ejemplo. El botón para copiar copia lo que ves.
  • Nota de LUZ. Indica si el elemento tiene estilos sin clase, mediante una clase de componente o si se deja al navegador.

Las reglas que dan estilo a elementos sin clase tienen especificidad cero: cualquier clase .luz-* o regla propia prevalece.

Elementos obsoletos y qué usar en su lugar

Los 23 elementos siguientes se excluyen deliberadamente de la referencia: están obsoletos o se han eliminado, y LUZ no aplica estilos a ninguno. Usa la alternativa indicada.

ElementoUsa en su lugarMotivoFuente
acronym
abbr
La misma función con el nombre que sigue vigente.
Estándar HTML: acronym
big
CSS: font-size, o strong o em cuando aporten énfasis
El tamaño es una cuestión de presentación.
Estándar HTML: big
center
CSS: text-align: center para texto, margin-inline: auto para un bloque
La alineación es una cuestión de presentación.
Estándar HTML: center
content
slot, de Shadow DOM versión 1
Formaba parte de la primera versión de Shadow DOM, que los navegadores eliminaron.
MDN: content
dir
ul
Una lista de archivos es una lista.
Estándar HTML: dir
fencedframe
iframe
Un experimento obsoleto de Privacy Sandbox.
MDN: fencedframe
font
CSS: font-family, font-size y color
Las fuentes y los colores son cuestiones de presentación.
Estándar HTML: font
frame
iframe y CSS, o inclusiones del lado del servidor
Los marcos dividen una ventana en documentos; una maquetación lo hace con CSS.
Estándar HTML: frame
frameset
iframe y CSS, o inclusiones del lado del servidor
Como con frame.
Estándar HTML: frameset
image
img
Nunca formó parte de un estándar: los navegadores solo lo mantuvieron por compatibilidad con páginas antiguas.
MDN: image
marquee
Animación CSS que respete prefers-reduced-motion
El texto en movimiento que no se puede pausar incumple WCAG 2.2.2.
Estándar HTML: marquee
menuitem
Un script en el evento contextmenu o un popover con botones
El marcado del menú contextual nunca llegó a implementarse de forma generalizada y se eliminó.
Estándar HTML: menuitem
nobr
CSS: white-space: nowrap
El salto de línea es una cuestión de presentación.
Estándar HTML: nobr
noembed
object en lugar de embed, con contenido alternativo dentro
embed no tiene contenido alternativo propio.
Estándar HTML: noembed
noframes
iframe y CSS, o inclusiones del lado del servidor
Como con frame.
Estándar HTML: noframes
param
El atributo data de object, que establece la URL del recurso
Parámetros de un plug-in que ningún navegador ejecuta.
Estándar HTML: param
plaintext
El tipo text/plain de la respuesta
No se podía cerrar: el resto de la página se convertía en texto.
Estándar HTML: plaintext
rb
El texto base directamente dentro de ruby
El texto base de ruby no necesita un contenedor.
Estándar HTML: rb
rtc
Elementos ruby anidados
Como con rb.
Estándar HTML: rtc
shadow
slot, de Shadow DOM versión 1
Formaba parte de la primera versión de Shadow DOM, que los navegadores eliminaron.
MDN: shadow
strike
del para una edición, s para texto que ya no es aplicable
El elemento indica qué significa el texto, no cómo se representa.
Estándar HTML: strike
tt
code, kbd, samp o var, según su significado, o CSS font-family: monospace
La anchura fija es una cuestión de presentación.
Estándar HTML: tt
xmp
pre con code, escapando < y &
No podía contener su propia etiqueta de cierre.
Estándar HTML: xmp
