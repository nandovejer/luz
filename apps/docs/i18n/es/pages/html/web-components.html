Crea elementos personalizados: una plantilla que se analiza pero no se muestra y un slot que muestra el contenido de la página dentro de un árbol shadow.

<slot>

MDN referencia del elemento slot

Un hueco en el árbol shadow de un componente web que la página rellena con su propio marcado. Un slot con nombre solo recibe los elementos cuyo atributo slot coincide con ese nombre.

Hello from the light DOM This text fills the default slot.
HTML 
<template id="d-slot-template">
  <style>
    article { padding: var(--luz-space-sm); border: 1px solid var(--luz-divider); }
    h4 { margin-bottom: var(--luz-space-2xs); }
  </style>
  <article>
    <h4><slot name="title">Untitled</slot></h4>
    <slot>No content.</slot>
  </article>
</template>

<demo-card>
  <span slot="title">Hello from the light DOM</span>
  This text fills the default slot.
</demo-card>

LUZ no añade estilos: slot no tiene caja propia y el contenido que recibe conserva sus estilos. El elemento personalizado necesita unas pocas líneas de script. Los tokens de diseño atraviesan el límite del shadow, así que la tarjeta sigue el modo de color.
