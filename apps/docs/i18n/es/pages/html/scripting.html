Dibuja con un script, indica qué ocurre si está desactivado y carga el propio script.

<canvas>

MDN referencia del elemento canvas

Un área de dibujo que pintas con un script, para gráficos o juegos. Los lectores de pantalla no pueden ver el dibujo, así que incluye dentro una alternativa textual.

A square and a circle.
HTML 
<canvas id="d-canvas" width="240" height="120" role="img" aria-label="A square and a circle, drawn with the canvas API">
  A square and a circle.
</canvas>

Con estilos de elements/media.css, sin clase. Este ejemplo se dibuja a partir de los valores de los tokens, por lo que sigue el modo de color.

<noscript>

MDN referencia del elemento noscript

Contenido que solo se muestra cuando los scripts están desactivados o no pueden ejecutarse. Esta tarjeta muestra solo el marcado: en esta página nunca se representaría.

Solo marcado: este elemento no se representa.

HTML 
<noscript>
  <p>This page needs JavaScript for the live demos.</p>
</noscript>

LUZ no añade estilos: cuando aparece, su contenido adopta los estilos de los elementos que contiene.

<script>

MDN referencia del elemento script

Ejecuta JavaScript, escrito en línea o cargado desde un archivo. Usa type="module" para los comportamientos de LUZ.

Solo marcado: este elemento no se representa.

HTML 
<script type="module" src="https://cdn.jsdelivr.net/npm/@luz-ds/core@0.1.0/dist/luz.min.js"></script>

LUZ no añade estilos: se mantiene el aspecto del navegador.
