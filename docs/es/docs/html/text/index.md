# Bloques de texto

Contienen el texto de lectura de una página: párrafos, listas, citas y texto preformateado.

- `<blockquote>`
- `<dd>`
- `<div>`
- `<dl>`
- `<dt>`
- `<figcaption>`
- `<figure>`
- `<hr>`
- `<li>`
- `<menu>`
- `<ol>`
- `<p>`
- `<pre>`
- `<ul>`
- Patrones de listas de descripciones
- Metadatos
- Pares de nombre y valor
- Glosario
