        Elementos HTML

        Bloques de texto

        ℹ
        Esta traducción la ha escrito una IA y todavía no la ha revisado ninguna persona. Leer esta página en inglés

        Contienen el texto de lectura de una página: párrafos, listas, citas y texto preformateado.

        <blockquote>

        MDN referencia del elemento blockquote

        Una cita extensa, separada en su propio bloque. Pon la URL de la fuente en el atributo cite e indica quién lo dijo fuera de la cita, por ejemplo, en un figcaption.

        The best interface is the one the browser already ships.

        HTML 
        <blockquote>
  <p>The best interface is the one the browser already ships.</p>
</blockquote>

        Con estilos de elements/text.css, sin clase.

        <dd>

        MDN referencia del elemento dd

        El valor o la explicación que sigue a dt en una lista de descripciones. Un término puede tener varios.

        Token
        A named design decision, stored as a variable.
        HTML 
        <dl>
  <dt>Token</dt>
  <dd>A named design decision, stored as a variable.</dd>
</dl>

        Con estilos de elements/text.css, sin clase.

        <div>

        MDN referencia del elemento div

        Una caja sencilla sin significado propio. Úsala solo si no encaja ningún otro elemento y asígnale una clase que explique su propósito.

        First block
        Second block
        HTML 
        <div class="o-stack">
  <div>First block</div>
  <div>Second block</div>
</div>

        LUZ no añade estilos: se mantiene el aspecto del navegador. LUZ no añade estilos. El objeto de maquetación o-stack separa sus elementos hijos.

        <dl>

        MDN referencia del elemento dl

        Una lista de nombres asociados a valores: un glosario, las especificaciones de un producto o los datos de un archivo. Cada dt nombra algo y el dd siguiente lo explica.

        Tokens
        Layer 1, standalone.
        Core
        Layer 2, requires tokens.
        HTML 
        <dl>
  <dt>Tokens</dt>
  <dd>Layer 1, standalone.</dd>
  <dt>Core</dt>
  <dd>Layer 2, requires tokens.</dd>
</dl>

        Con estilos de elements/text.css, sin clase.

        <dt>

        MDN referencia del elemento dt

        La parte del nombre de un par nombre-valor en una lista de descripciones, como una palabra de un glosario. LUZ la muestra con un peso mayor.

        Site
        Layer 3, site patterns.
        HTML 
        <dl>
  <dt>Site</dt>
  <dd>Layer 3, site patterns.</dd>
</dl>

        Con estilos de elements/text.css, sin clase.

        <figcaption>

        MDN referencia del elemento figcaption

        El pie de una figura. Colócalo como primer o último elemento hijo de figure.

        HTML 
        <figure>
  <img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120">
  <figcaption>Two shapes, drawn in SVG.</figcaption>
</figure>

        Con estilos de elements/text.css, sin clase.

        <figure>

        MDN referencia del elemento figure

        Envuelve una imagen, un diagrama, un bloque de código o una cita a la que hace referencia el texto, con un pie opcional. Se podría mover a otro lugar de la página sin romper el texto.

        HTML 
        <figure>
  <img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120">
  <figcaption>Two shapes, drawn in SVG.</figcaption>
</figure>

        Con estilos de elements/text.css, sin clase. LUZ convierte una figure sin clase en una superficie con relleno. El componente .luz-figure añade más estilos.

        <hr>

        MDN referencia del elemento hr

        Marca un cambio de tema o de escena entre párrafos. Úsala con ese significado, no como línea decorativa: para una línea sencilla, usa un borde.

        Above the break.

        Below the break.

        HTML 
        <p>Above the break.</p>
<hr>
<p>Below the break.</p>

        Con estilos de elements/text.css, sin clase.

        <li>

        MDN referencia del elemento li

        Un elemento de una lista. Su padre es ol, ul o menu.

        • Tokens
        • Core
        • Site
        HTML 
        <ul>
  <li>Tokens</li>
  <li>Core</li>
  <li>Site</li>
</ul>

        LUZ no añade estilos: se mantiene el aspecto del navegador.

        <menu>

        MDN referencia del elemento menu

        Una lista de acciones que se pueden realizar, como los botones de una barra de herramientas. Los navegadores la tratan como ul; LUZ la distribuye en una fila.

        •
        HTML 
        <menu>
  <li><button class="luz-btn luz-btn--outline luz-btn--sm" type="button">Cut</button></li>
  <li><button class="luz-btn luz-btn--outline luz-btn--sm" type="button">Copy</button></li>
  <li><button class="luz-btn luz-btn--outline luz-btn--sm" type="button">Paste</button></li>
</menu>

        Con estilos de elements/text.css, sin clase.

        <ol>

        MDN referencia del elemento ol

        Una lista cuyo orden importa, como una serie de pasos o una clasificación. Una lista sin clase recupera los marcadores dentro de su caja.

        1. Install the tokens.
        2. Add the core.
        3. Add the site package.
        HTML 
        <ol>
  <li>Install the tokens.</li>
  <li>Add the core.</li>
  <li>Add the site package.</li>
</ol>

        Con estilos de elements/text.css, sin clase.

        <p>

        MDN referencia del elemento p

        Un párrafo de texto. LUZ pide al navegador que evite dejar una sola palabra aislada en la última línea.

        LUZ is a vanilla design system: tokens, components and app patterns in plain CSS and ES modules, with no framework and no build step.

        HTML 
        <p>LUZ is a vanilla design system: tokens, components and app patterns in plain CSS and ES modules, with no framework and no build step.</p>

        Con estilos de elements/text.css, sin clase.

        <pre>

        MDN referencia del elemento pre

        Texto que se muestra exactamente como se ha escrito, con todos los espacios y saltos de línea, en una fuente de ancho fijo. Para el código, añade la clase .luz-code-block y un elemento code.

        $ pnpm add @luz-ds/tokens
            $ pnpm add @luz-ds/core
        HTML 
        <pre>$ pnpm add @luz-ds/tokens
$ pnpm add @luz-ds/core</pre>

        Con estilos de elements/text.css, sin clase.

        <ul>

        MDN referencia del elemento ul

        Una lista cuyo orden no importa, como una lista de características o ingredientes. Una lista sin clase recupera los marcadores dentro de su caja.

        • Tokens
        • Core
        • Site
        HTML 
        <ul>
  <li>Tokens</li>
  <li>Core</li>
  <li>Site</li>
</ul>

        Con estilos de elements/text.css, sin clase.

        Patrones de listas de descripciones

        Tres formas de usar <dl> con los estilos anteriores. Puedes agrupar cada <dt> con su <dd> en un <div>: es HTML válido y LUZ mantiene el mismo espacio entre grupos.

        Metadatos

        Datos sobre algo, como un archivo o un pedido. Cada par tiene un nombre y un valor, y va en su propio div para que un script o una regla de estilo pueda seleccionarlo.

        File
        annual-report.pdf
        Size
        2.4 MB
        Last changed
        9 October 2026
        HTML 
        <dl>
  <div>
    <dt>File</dt>
    <dd>annual-report.pdf</dd>
  </div>
  <div>
    <dt>Size</dt>
    <dd>2.4 MB</dd>
  </div>
  <div>
    <dt>Last changed</dt>
    <dd><time datetime="2026-10-09">9 October 2026</time></dd>
  </div>
</dl>

        Usa <time> con datetime para las fechas. Los nombres son sustantivos breves y los valores, texto sin formato.

        Pares de nombre y valor

        Un resumen de ajustes o detalles. Un nombre puede tener varios valores: repite dd, uno por cada valor.

        Plan
        Team
        Members
        Ana Ruiz
        Luis Pérez
        Billing email
        billing@example.com
        HTML 
        <dl>
  <div>
    <dt>Plan</dt>
    <dd>Team</dd>
  </div>
  <div>
    <dt>Members</dt>
    <dd>Ana Ruiz</dd>
    <dd>Luis Pérez</dd>
  </div>
  <div>
    <dt>Billing email</dt>
    <dd><a href="mailto:billing@example.com">billing@example.com</a></dd>
  </div>
</dl>

        Si un nombre tiene varios valores, todos forman un mismo grupo: el lector de pantalla anuncia cada valor por turno.

        Glosario

        Términos y sus significados. Cada término es un dt con un dfn dentro y tiene un id para que otras páginas puedan enlazar a su entrada.

        Design token
        A named value, such as a color or a space, that components read.
        Color mode
        One set of color values for the whole page.
        Light, dark and high contrast are the three LUZ ships.
        HTML 
        <dl>
  <dt id="term-token"><dfn>Design token</dfn></dt>
  <dd>A named value, such as a color or a space, that components read.</dd>
  <dt id="term-mode"><dfn>Color mode</dfn></dt>
  <dd>One set of color values for the whole page.</dd>
  <dd>Light, dark and high contrast are the three LUZ ships.</dd>
</dl>

        Enlaza a un término con #term-token. Un término puede tener más de un significado: repite dd.

        Antes de usarlo

        • Mantén el valor predeterminado de display de <dl> y sus grupos. Definir flex o grid en elementos de lista ha hecho que algunas combinaciones de navegador y lector de pantalla pierdan la semántica de lista; consulta Propiedades display de CSS frente a la semántica de HTML. Distribuye los pares en un contenedor que controles y prueba el resultado.
        • HTML solo permite un <div> dentro de <dl> cuando envuelve un nombre y sus valores. Una fuente que probó un div como contenedor simple detectó problemas con lectores de pantalla en algunos navegadores (Uso de div en dl; no ofrece resultados). LUZ no ha probado el marcado agrupado con NVDA, JAWS, VoiceOver, TalkBack ni Orca.
        • Para una tabla con muchos valores por fila, usa una tabla, no una lista de descripciones.
