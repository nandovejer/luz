        Tablas

        ℹ
        Esta traducción la ha escrito una IA y todavía no la ha revisado ninguna persona. Leer esta página en inglés

        Muestra datos en filas y columnas. Una tabla sin clase no tiene estilos de LUZ: añade .luz-table y envuélvela en .luz-table-wrap para que pueda desplazarse.

        <caption>

        MDN referencia del elemento caption

        El título de una tabla, que los lectores de pantalla leen junto con ella. Debe ser su primer elemento hijo.

        Packages and their layer
        PackageLayer
        tokens1
        core2
        HTML 
        <div class="luz-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="luz-table">
    <caption>Packages and their layer</caption>
    <thead>
      <tr><th>Package</th><th>Layer</th></tr>
    </thead>
    <tbody>
      <tr><td>tokens</td><td>1</td></tr>
      <tr><td>core</td><td>2</td></tr>
    </tbody>
  </table>
</div>

        Estilizado mediante su clase, de components/table.css.

        <col>

        MDN referencia del elemento col

        Una columna, o varias si se usa span, dentro de colgroup. Sirve para definir el ancho, el fondo o el borde de una columna entera.

        PackageLayer
        tokens1
        core2
        HTML 
        <div class="luz-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="luz-table">
    <colgroup><col><col style="background: var(--luz-brand-subtle)"></colgroup>
    <thead>
      <tr><th>Package</th><th>Layer</th></tr>
    </thead>
    <tbody>
      <tr><td>tokens</td><td>1</td></tr>
      <tr><td>core</td><td>2</td></tr>
    </tbody>
  </table>
</div>

        LUZ no añade estilos: se mantiene el aspecto del navegador.

        <colgroup>

        MDN referencia del elemento colgroup

        Agrupa las columnas de una tabla para que puedas ajustar su tamaño o color a la vez. Va después de caption y antes de las filas.

        LUZ no añade estilos: en las columnas solo se aplican el ancho, el fondo, el borde y la visibilidad, y los valores adecuados dependen de cada tabla.

        <table>

        MDN referencia del elemento table

        Datos en filas y columnas que se comparan, nunca para maquetar una página. Añade .luz-table a la tabla y envuélvela en .luz-table-wrap.

        PackageLayer
        tokens1
        core2
        HTML 
        <div class="luz-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="luz-table">
    <thead>
      <tr><th>Package</th><th>Layer</th></tr>
    </thead>
    <tbody>
      <tr><td>tokens</td><td>1</td></tr>
      <tr><td>core</td><td>2</td></tr>
    </tbody>
  </table>
</div>

        Estilizado mediante su clase, de components/table.css. Por debajo de 480px de ancho, la tabla se convierte en tarjetas: la fila de encabezados queda oculta a la vista, pero sigue disponible para los lectores de pantalla.

        <th>

        MDN referencia del elemento th

        Una celda que etiqueta una fila o columna. Define scope="col" o scope="row" para que los lectores de pantalla sepan qué celdas etiqueta.
