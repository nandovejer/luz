# Estructura de página

Construye los bloques principales de una página: regiones, encabezados y las secciones entre ellos. Parecen cajas sencillas; su valor está en lo que comunican a las tecnologías de asistencia.

- `<address>`
- `<article>`
- `<aside>`
- `<footer>`
- `<h1>`
- `<h2>`
- `<h3>`
- `<h4>`
- `<h5>`
- `<h6>`
- `<header>`
- `<hgroup>`
- `<main>`
- `<nav>`
- `<search>`
- `<section>`
