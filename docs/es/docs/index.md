# Documentación de LUZ

Instala LUZ, encuentra un componente y copia su marcado, o consulta un token, un patrón de página o un elemento HTML.

Instala LUZ, encuentra un componente y copia su marcado. Cada ejemplo es interactivo y sigue el modo de color que elijas.

Beta Los nombres y las clases aún pueden cambiar. Fija una versión exacta. [Lee el registro de cambios](https://github.com/nandovejer/luz/blob/main/CHANGELOG.md)

[Explora el índice alfabético](https://nandovejer.github.io/luz/es/docs/a-z/) Busca componentes, tokens y elementos HTML por nombre.

### Empieza aquí

- #### Primeros pasos
  Instala solo los tokens, añade los componentes o usa el stack completo. Con un comando o pegando las etiquetas de CDN.
- #### Componentes
  32 componentes con una demostración interactiva, el marcado que puedes copiar y cuándo usar cada uno.

### Más información

- [Tokens](https://nandovejer.github.io/luz/es/docs/tokens/) Colores, espaciado, tipografía y movimiento en los modos claro, oscuro y de alto contraste.
- [Site](https://nandovejer.github.io/luz/es/docs/site/) Patrones de página: estructura, cabecera, secciones, pie de página y búsqueda.
- [Elementos HTML](https://nandovejer.github.io/luz/es/docs/html/) Cómo aplica LUZ estilos a cada uno de los 116 elementos HTML.
- [Accesibilidad](https://nandovejer.github.io/luz/es/docs/accessibility/) Qué se prueba, qué no y cuáles son los problemas conocidos.

### Cómo funcionan estas páginas

- Cada página de componente y patrón muestra primero un ejemplo interactivo y sus problemas conocidos, y después dos pestañas: **Código** para desarrolladores y **Diseño** para diseñadores.
- Las páginas se abren en Código. Si eliges Diseño, la siguiente también se abrirá en Diseño: este navegador recuerda tu última elección, igual que recuerda el modo de color. No se envía nada.
- Sin JavaScript, las dos pestañas se muestran una detrás de otra.
