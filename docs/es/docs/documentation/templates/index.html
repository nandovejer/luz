        Plantillas de documentación

        Una página de documentación completa para copiar y adaptar, la navegación de la primera y la última página y lo que aún no incluye el paquete.

        ℹ
        Esta traducción la ha escrito una IA y todavía no la ha revisado ninguna persona. Leer esta página en inglés

        Cada plantilla es un marcado que puedes copiar en tu sitio, sustituyendo el texto de ejemplo por el tuyo. Solo usan clases de core y docs.

        La primera es una página completa; la segunda, una pieza que cambia al principio y al final de una secuencia. La última sección indica qué no incluye aún el paquete.

        Página de documentación

        Una página completa: el enlace para saltar al contenido, la cabecera, la barra lateral, el índice lateral, el contenido con su cabecera, un ejemplo y un par de qué hacer y qué no, la navegación entre páginas y el pie de página, seguidos del pie de sitio, dentro de la estructura.

        • Carga el CSS de tokens, core y docs, en ese orden: Instalar LUZ incluye el comando. El script de core es opcional: marca en el índice lateral la sección visible y cierra el cajón al seguir un enlace.
        • La estructura coloca las columnas, así que el código fuente mantiene el orden de lectura: barra lateral, índice lateral y contenido.
        • Los enlaces de la barra lateral y del índice lateral son ejemplos. El índice recoge los h2 de la página y sus h3 en una lista anidada.
        • A partir de 80rem, la estructura siempre tiene tres columnas. Sin <aside>, la tercera queda vacía, así que incluye el índice lateral en todas las páginas del sitio. Por debajo de 80rem, el índice se muestra encima del contenido, bajo la cabecera.

        Primera y última página

        La primera página de una secuencia no tiene página anterior y la última no tiene página siguiente. Omite el otro elemento: si solo hay un enlace a la página siguiente, queda al final de la fila; si solo hay uno a la anterior, queda al principio.

        • No añadas un enlace sin destino para mantener los dos bloques: un bloque vacío es un enlace que no hace nada.
        • Si una página forma parte de dos secuencias, usa una sola navegación entre páginas y decide a cuál pertenece.

        Qué no incluye

        Un sitio de documentación suele necesitar funciones que el paquete no incluye. Las plantillas de arriba no las simulan.

        • Búsqueda. Usa la búsqueda de site, un peer opcional de este paquete.
        • Resaltado de sintaxis y botón para copiar el código. Los ofrece el bloque de código de core, junto con su script.
        • Un selector de anchura para el ejemplo y controles en vivo que lo modifican. El marco lee --luz-docs-example-w; tú tienes que crear el control que le asigna el valor.
        • Un script para «Copiar la página como Markdown». El índice lateral incluye el enlace; tú tienes que copiar su destino.
        • Versiones, traducciones y un registro de cambios. Son contenido de tu sitio.
