# Plantillas de páginas de aterrizaje

Los bloques de una página de aterrizaje para un evento, listos para copiar y adaptar en el orden en que los lee quien la visita: hero, programa, ponentes, entradas, llamada a la acción, inscripción y características; además, una página de producto que reúne un hero centrado, la cabecera de una sección, estadísticas y un pie con columnas.

This page is a library of whole-page templates: open its URL for the markup of each.
