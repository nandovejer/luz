# Elige tu fragmento

Elige qué estás creando y cómo lo cargas; después, copia las líneas. Las líneas de CDN incluyen hashes de integridad calculados a partir de los archivos publicados.

Cada fragmento carga primero los tokens, luego core y, por último, el paquete para el tipo de sitio que uses, en el orden que esperan las [capas de cascada](https://nandovejer.github.io/luz/es/docs/get-started/layers/). El paquete site es opcional para una landing page, un blog y una aplicación, por eso sus líneas están marcadas y puedes eliminarlas sin riesgo.

Para ver la explicación paso a paso, lee [Instalar LUZ](https://nandovejer.github.io/luz/es/docs/get-started/); si usas una herramienta de compilación, consulta [Con un empaquetador o framework](https://nandovejer.github.io/luz/es/docs/get-started/bundler/).
