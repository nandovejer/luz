        Elige tu fragmento

        Elige qué estás creando y cómo lo cargas; después, copia las líneas. Las líneas de CDN incluyen hashes de integridad calculados a partir de los archivos publicados.

        ℹ
        Esta traducción la ha escrito una IA y todavía no la ha revisado ninguna persona. Leer esta página en inglés

        Cada fragmento carga primero los tokens, luego core y, por último, el paquete para el tipo de sitio que uses, en el orden que esperan las capas de cascada. El paquete site es opcional para una landing page, un blog y una aplicación, por eso sus líneas están marcadas y puedes eliminarlas sin riesgo.

        Para ver la explicación paso a paso, lee Instalar LUZ; si usas una herramienta de compilación, consulta Con un empaquetador o framework.

        Archivos que se cargan bajo demanda

        Core y site solo cargan algunos archivos cuando la página los necesita: una tabla ordenable, una línea de tiempo, un reproductor MIDI, una página en español, la búsqueda o el banner de cookies. El hash de un script solo cubre ese archivo, así que cada archivo necesita su propio hash. Para proporcionárselo en todos los navegadores, usa un mapa de importaciones con una sección integrity, antes del primer script de módulo: así, el navegador comprueba cada archivo cuando el script lo importa y no ejecuta los archivos cuyo hash no coincide.

        Safari y Firefox no usan el valor integrity de un <link rel="modulepreload"> para bloquear un archivo, así que solo sirve como indicación de rendimiento: úsalo, si quieres, para descargar un archivo antes, pero no confíes en él como comprobación. El mapa de importaciones de abajo enumera todos esos archivos. Conserva solo las líneas correspondientes a lo que incluye la página, como indica la tabla: un hash de un archivo que la página nunca carga no sirve de nada.

        HTML 
        <script type="importmap">
{
  "integrity": {

        Comprueba un hash por tu cuenta

        Todos los hashes de esta página se calculan a partir del archivo que publica el paquete al compilar la documentación. Para comprobar uno, descarga el archivo que cargas y calcula su hash del mismo modo:

        Shell 
        curl -s <url of the file> | openssl dgst -sha384 -binary | openssl base64 -A

        El resultado, después de sha384-, es el valor de integrity. Si no coincide con el de la página, no cargues el archivo: la versión de la URL o el propio archivo han cambiado.
