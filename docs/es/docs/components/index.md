# Componentes

Todos los componentes de core, agrupados por tarea, con un ejemplo en vivo, el marcado que puedes copiar y cuándo usarlos.

Un **componente** es una pieza reutilizable, casi siempre asociada a un elemento HTML: un botón, un campo, una tabla. Un **patrón** combina componentes para realizar una tarea del producto, como la estructura de una página o la búsqueda del sitio; los patrones están en [Site](https://nandovejer.github.io/luz/es/docs/site/).
