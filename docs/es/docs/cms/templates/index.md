# Plantillas de CMS

Las partes de un blog o periódico que no necesitan CSS propio, listas para copiar y adaptar: la página de contenido, la página de artículo, una tarjeta de artículo, listas de artículos, artículos relacionados y el recuadro del autor.

This page is a library of whole-page templates: open its URL for the markup of each.
