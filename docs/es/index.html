        Light, usable & zero-dependency

        LUZ, sistema de diseño para el humano, listo para la IA

        Tokens, CSS y un poco de JavaScript, sobre lo que el navegador ya hace. Cada componente funciona antes de que cargue JavaScript y nos encanta TDD, cada cambio empieza con una prueba que falla.

        Leer la documentación, en inglés Ver el código en GitHub

        La luz donde estás

        Con JavaScript activado, aquí se dibuja la luz de tu hora.

        Por qué LUZ

        Tres palabras, una promesa.

        Un sistema de diseño para la web que parte del CSS y no necesita compilación. Tu CSS siempre gana, JavaScript solo mejora la experiencia y cada página funciona antes de que cargue.

        Light

        Ligero: CSS sin más y módulos ES pequeños desde un CDN o npm. Sin preprocesador ni compilador: lo que lees en los archivos es lo que ejecuta el navegador.

        Esta página sigue tu reloj. Toca una luz para ver la página a otra hora.

        Usable

        Usable: lo nativo primero, con dialog, popover, details, range y progress. El teclado, el foco visible y un contraste de texto de 4,5:1 forman parte de cada componente; no son una opción.

        Eso ha sido solo el teclado. Pulsa Escape para cerrar esta nota.

        El anillo de foco toma el color de las acciones de la página, y nunca se oculta.

        Zero-dependency

        0

        dependencias en tiempo de ejecución. Nada que instalar para probarlo y ningún framework que seguir durante años.

        Qué incluye

        Adóptalo capa a capa.

        Una sola dirección: cada paquete necesita los que tiene debajo y nada de lo que tiene encima, y al instalarlo los trae consigo. Elige el nivel que necesitas y quédate ahí.

        Nivel 1 Solo tokens

        Independiente

        Elígelo si ya tienes componentes o un framework y solo quieres valores coherentes y modos de color.

        Incluye

        • 53 colores primitivos y 55 tokens semánticos, estos definidos para claro, oscuro y alto contraste
        • Escalas de espaciado, alturas de control, tamaños de texto, radios y sombras
        Instalar el nivel 1 Ver los tokens

        Nivel 2 Tokens + Core

        Necesita tokens

        Elígelo si construyes páginas o una aplicación y la maquetación de la página la pones tú.

        Añade al nivel 1

        • 32 componentes, de botones y formularios a pestañas y un reproductor multimedia, y 10 objetos de maquetación
        • Todo en una sola capa de cascada, luz: tu propio CSS gana sin !important
        Instalar el nivel 2 Ver los componentes

        Nivel 3 Tokens + Core + Site

        Necesita core + tokens

        Elígelo si tu sitio necesita una búsqueda, un aviso de cookies o más de un idioma. Esta página de inicio está construida sobre él.

        Añade al nivel 2

        • Búsqueda en el sitio y un aviso de cookies que no tapa nada, con JavaScript opcional
        • Un selector de idioma, submenús para los enlaces de una cabecera y un aviso encima de ella
        Instalar el nivel 3 Ver los patrones

        Nivel 4 · un paquete para tu tipo de sitio

        Cada uno se construye sobre site. Instala el de tu sitio: trae todo lo que tiene debajo.

        • landing para una landing page
        • cms para un blog o un periódico
        • app para una aplicación web

        Funciona sin JavaScript

        Parte de lo que el navegador ya hace.

        Cada componente es un elemento nativo con una hoja de estilos encima. Desactiva JavaScript y siguen abriéndose, cerrándose, deslizándose y dejando elegir.

        <details>

        ¿Qué significa «sin compilación»?

        Que no hay ningún paso entre los archivos que lees y la página que muestra el navegador. Los copias, los enlazas y listo.

        <dialog>

        Se abre sin script donde el navegador tiene command; en los demás lo abre un pequeño script.

        Un diálogo nativo

        El foco entra en él, Escape lo cierra y el navegador deja fuera de alcance la página de detrás. Ninguna biblioteca ha escrito nada de eso.

        popover

        Se cierra al pulsar fuera y va en la capa superior, sin pelearse con z-index. Lo resuelve el navegador.

        Tres modos de color

        Claro, oscuro, alto contraste. Y la hora.

        Cada color semántico está definido para los tres modos, y el atributo data-theme los cambia, en toda la página o en una parte. Esta página añade un eje propio: la hora del lugar donde estás.

        Primeros pasos

        Una etiqueta <link> por capa.

        Elige un nivel, copia el fragmento y publica. Fija una versión exacta mientras LUZ esté en beta.

        Desde un CDN 
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/tokens@0.0.0/dist/luz-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/core@0.0.0/dist/luz.min.css">

<button class="luz-btn luz-btn--primary">Guardar los cambios</button>
<span class="luz-tag luz-tag--green luz-tag--dot">Publicado</span>

        Así se ve

        Publicado
        Desde npm 
        npm install @luz-ds/tokens @luz-ds/core

import "@luz-ds/tokens/css";
import "@luz-ds/core/css";
import "@luz-ds/core";

        Después, escribe HTML. <button class="luz-btn"> es un botón. <dialog class="luz-modal"> es un diálogo modal. Esa es toda la idea.

        Encaja bien

        • Sitios de contenido, documentación y servicios públicos que deben cumplir WCAG 2.2 AA.
        • Páginas generadas en el servidor y sitios estáticos, con cualquier lenguaje de servidor.
        • Equipos que quieren entender su CSS y controlarlo.

        No encaja

        • Necesitas componentes de React o Vue ya hechos.
        • Necesitas una tabla de datos avanzada, gráficos o un selector de rango de fechas: LUZ no los incluye.
        • Necesitas una API estable hoy: LUZ está en beta y los nombres aún pueden cambiar.
