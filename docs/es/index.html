        LUZ Sistema de diseño para el humano, listo para la IA

        Tokens, CSS y un poco de JavaScript, sobre lo que el navegador ya hace. Cada componente funciona antes de que cargue JavaScript y cada cambio empieza con una prueba que falla.

        Primeros pasos Leer la documentación, en inglés

        La luz donde estás

        Con JavaScript activado, aquí se dibuja la luz de tu hora.

        Base

        Tu marca, en tokens

        Colores, escalas y los tres modos como propiedades personalizadas de CSS. Sin componentes: tu marcado, tus clases.

        • Colores. 53 primitivos y 55 tokens semánticos, en claro, oscuro y alto contraste.
        • Escalas. Espacio, texto, radios y sombras, desde tres mandos.
        • Peso. 2,8 KB en gzip, con todo lo anterior.

        Por qué LUZ

        Tres palabras, una promesa.

        Un sistema de diseño para la web que parte del CSS y no necesita compilación. Tu CSS siempre gana, JavaScript solo mejora la experiencia y cada página funciona antes de que cargue.

        Light

        Poco código y ningún paso de compilación.

        CSS sin más y módulos ES pequeños, desde un CDN o desde npm. Sin preprocesador, sin compilador y sin paso de build: lo que lees en los archivos es justo lo que ejecuta el navegador, y cada paquete tiene un techo de peso que nunca sube.

        Usable

        Accesible de serie, no con parches.

        Pensado para WCAG 2.2 AA y EN 301 549, la norma europea de accesibilidad digital. Parte de lo que el navegador ya hace bien, añade foco visible, contraste y movimiento reducido, y lo comprueba con axe en cada cambio. Lee la declaración.

        Zero-dependency

        Tu código, no un árbol del código de otros.

        Los paquetes de LUZ se publican sin dependencias: solo CSS y módulos ES sobre lo que el navegador ya ofrece. Nada que instalar para probarlo, ningún framework que seguir y nada que se rompa cuando otra librería publica una versión mayor.

        Encaja bien

        • Sitios de contenido, documentación y servicios públicos que deben cumplir WCAG 2.2 AA.
        • Páginas generadas en el servidor y sitios estáticos, con cualquier lenguaje de servidor.
        • Equipos que quieren entender su CSS y controlarlo.

        No encaja

        • Necesitas componentes de React o Vue ya hechos.
        • Necesitas una tabla de datos avanzada, gráficos o un selector de rango de fechas: LUZ no los incluye.
        • Necesitas una API estable hoy: LUZ está en beta y los nombres aún pueden cambiar.

        HTML semántico, con estilo

        Una etiqueta, una clase, cero JS

        Escribe el elemento que quieres decir. Añade la clase de LUZ. El navegador hace el resto.

        • Sin script. 22 de 32 componentes son solo CSS: nada que cargar.
        • Una clase cada uno. Un componente es un elemento nativo y una clase: sin envoltorios ni cadenas de utilidades.
        • El resto, con red. Los otros 10 mejoran con un script, y cada página dice qué obtienes sin él.

        Tres modos de color

        Una interfaz, tres modos

        Cada color semántico está definido para claro, oscuro y alto contraste. Un atributo, data-theme, los cambia: en toda la página o en una parte, como en cada caja de abajo.

        Claro

        Claro, para leer de día

        Papel cálido y tinta marrón: el tono de Vejer. Es el modo por defecto: sin data-theme, la página se ve así.

        Oscuro

        Oscuro, para la noche

        Fondos profundos y un texto claro que no deslumbra. Los mismos tokens con otros valores: ningún componente cambia una línea.

        Alto contraste

        Alto contraste, para ver cada borde

        Negro sobre blanco y bordes marcados, para quien necesita más. No es el modo oscuro: es un modo propio, medido como los otros dos.
