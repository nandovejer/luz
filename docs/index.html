        LUZ Design system for humans, ready for AI.

        Tokens, CSS and a little vanilla JavaScript, built on what the browser already does. Every component works before JavaScript loads, and every change starts with a failing test.

        Base

        Your brand, as tokens

        Colors, scales and the three modes as CSS custom properties. No components: your markup, your classes.

        • Colors. 53 primitives and 55 semantic tokens, in light, dark and high contrast.
        • Scales. Space, type, radii and shadows, from three knobs.
        • Weight. 2.8 KB gzipped, with everything before it.

        Why LUZ

        Three words, one promise.

        A CSS-first, zero-build design system for the web. Your CSS always wins, JavaScript is only an enhancement, and every page works before it loads.

        Light

        Little code, no build step.

        Plain CSS and small ES modules, from a CDN or from npm. No preprocessor, no compiler and no build step: what you read in the files is exactly what the browser runs, and each package has a size ceiling that never goes up.

        Usable

        Accessible by default, not by add-on.

        Built to WCAG 2.2 AA and EN 301 549, the EU standard for accessible digital products. It starts from what the browser does well, adds visible focus, contrast and reduced motion, and checks them with axe on every change. Read the statement.

        Zero-dependency

        Your code, not a tree of someone else’s.

        LUZ’s packages ship with no dependencies: only CSS and ES modules over what the browser already offers. Nothing to install to try it, no framework to keep up with, and nothing that breaks when another library ships a new major version.

        A good fit

        • Content sites, documentation and public services that must meet WCAG 2.2 AA.
        • Server-rendered pages and static sites, in any back-end language.
        • Teams that want to read and own their CSS.

        Not a good fit

        • You need ready-made React or Vue components.
        • You need a data grid, charts or a date-range picker: LUZ has none.
        • You need a stable API today: LUZ is in beta, and names can still change.

        Semantic HTML, styled

        One tag, one class, zero JS

        Write the element you mean. Add LUZ's class. The browser does the rest.

        • No script. 22 of 32 components are CSS only: nothing to load.
        • One class each. A component is a native element and one class: no wrappers, no utility chains.
        • The rest, with a net. The other 10 improve with a script, and each page says what you get without it.

        Three color modes

        One interface, three modes

        Every semantic color is defined for light, dark and high contrast. One attribute, data-theme, switches them: on the whole page, or on one part of it, like each box below.

        Light

        Light, for reading by day

        Warm paper and brown ink: Vejer's tone. It is the default: with no data-theme, the page looks like this.

        Dark

        Dark, for the night

        Deep surfaces and light text that does not glare. The same tokens with other values: no component changes a line.

        High contrast

        High contrast, to see every edge

        Black on white and marked edges, for the reader who needs more. Not dark mode: a mode of its own, measured like the other two.
